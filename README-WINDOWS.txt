Latent v2 - Windows preview

Run the Setup EXE to install for your Windows account. No system Python,
Node.js, Git, or CUDA development toolkit is needed to start the desktop app.
The app opens after installation and is available in Start and on the desktop.

In the app, use Setup to check your hardware and storage, install the private
generation engine, and choose the image, editing or video components you need.
Internet access and a compatible NVIDIA driver are required for engine setup.
The driver remains a user-managed prerequisite. Downloads show a review first.
Existing ComfyUI installations are not imported automatically.

Studio data lives in %LOCALAPPDATA%\Latentv2 unless explicitly configured.
Settings shows its exact location. Uninstalling the app preserves your studio,
models and generated images. Reinstalling the app can reuse the same studio.

This preview is unsigned. A clean Windows-machine acceptance test and signing
remain pending. Optional model weights are downloaded separately, not bundled.

LICENSE contains the app MIT license. THIRD-PARTY-NOTICES.txt lists dependency
licenses and native-library information. LICENSE.electron.txt and
LICENSES.chromium.html contain the Electron and Chromium notices.
